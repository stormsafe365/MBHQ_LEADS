Lead Tracker — Setup

One-time connection to your Supabase project.

  1. Create a free project at supabase.com.
  2. In the dashboard, open SQL Editor, paste the contents of supabase-setup.sql (in this folder), and run it.
  3. Open Project Settings → API, copy the Project URL and the anon public key.
  4. Open index.html in a text editor and paste both into the CONFIG block at the top of the script.
  5. In Authentication → Users, click Add user for each rep: email first.last@local.com, password = their 6-digit PIN, check Auto Confirm User.
  6. Reload this page and sign in.
